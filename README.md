## 先分清三种 WordPress 主机

三种类型的区别就一句话：出了问题谁来管。

**共享主机**是把一台服务器分给很多用户，给你 cPanel 后台和一键装 WordPress，出事找客服。**托管型 WordPress 主机**更进一步，核心更新、备份、安全补丁、性能优化都由主机商代办，代价是价格普遍贵出一个量级。**自管 VPS** 则是租一台有独立资源的虚拟服务器，WordPress 环境完全自己装、自己管。

不管选哪种，真正值得核对的只有四件事：

1. 正常运行时间有没有 99.9% 以上的记录——99% 听着挺高，换算下来一年有三天多打不开网站
2. **续费价**，而不是首年促销价
3. 退款期多长、什么条件
4. 机房位置：给中国大陆读者看，美国西海岸机房通常比美东快不少；有新加坡节点的（SiteGround、hosting.com 都有）对亚洲访问更友好

这四条会比任何“十大推荐”榜单都管用，因为它们直接对应你以后会遇到的麻烦。

4. 把域名 A 记录解析到 VPS 的 IPv4 地址
5. 在面板里给站点签发 Let's Encrypt 免费证书，开启 HTTPS
6. 安装 WordPress

最后一步做完还有一件事必须自己做：**设置备份**。托管主机每天替你备份（GoDaddy 的方案保留最近 30 天），VPS 没有这个待遇，用面板的定时任务或插件定期把数据库和文件备份到异地，是自管 VPS 唯一不能省的习惯。

## 几个常见问题

**一年十几美元的 VPS 跑 WordPress 靠谱吗？**
靠谱，但有前提。1GB 内存配合缓存插件跑单个轻量博客没有问题，1TB 月流量对个人站点绰绰有余。前提是你接受自己负责维护，并且重要数据自己做异地备份。

**RackNerd 支持支付宝吗？**
它的支付渠道是 PayPal 和国际信用卡，不包含支付宝。前文提过，这在海外主机商里是常态，并非 RackNerd 一家的问题。

**用海外主机需要备案吗？**
不需要。RackNerd 的机房在美国和荷兰，域名解析到这些服务器不涉及 ICP 备案，这也是很多人选国外主机的原因之一。

**到底选托管主机还是 VPS？**
看动手意愿和站点性质：写作为主、不想管技术，选托管；预算优先、愿意折腾、多站复用，选 VPS。两边都有明确胜出的场景，不存在唯一答案。
